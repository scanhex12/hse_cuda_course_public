# MoE selection

в ML есть метод MoE. Суть в следующем - модель состоит из нескольких специализированных подсетей-экспертов, каждая из которых лучше решает определённый тип задач или обрабатывает определённые данные. Специальный маршрутизатор решает, какие эксперты должны обработать конкретный вход

В этой задаче представим, что у нас есть E экспертов и N токенов. Для каждого токена необходимо выбрать k экспертов с наилучшей оценкой. Для выбранных экспертов необходимо посчитать softmax.

Поскольку в реальных задачах E не очень большое, то считайте `1 <= k <= E <= 256`

Пример:

Предположим у нас есть выходы

```
1 2 3 4
4 3 2 1
```

N=4, E=2.

Если k = 2, то надо вернуть индексы 

```
2 3
0 1
```

softmax будет равен

```
0.2689, 0.7311
0.7311, 0.2689
```
