# Графы: кратчайшие пути (SSSP), delta-stepping на CUDA

## Задача

Дан взвешенный ориентированный граф с неотрицательными весами рёбер в формате CSR на CPU. Нужно для одной стартовой вершины `source` найти длины кратчайших путей до всех вершин и записать их в массив `distances_out`.

## Delta stepping

Алгоритм был разобран на семинаре, но идею можно посмотреть тут

https://ics-websites.science.uu.nl/docs/vakken/b3cc/resources/07-Delta-stepping.pdf

## Формат CSR

Граф задан в **CSR** (Compressed Sparse Row): три массива на CPU, по одному на каждое ребро.

| Массив | Длина | Смысл |
|--------|-------|--------|
| `csr_row_ptr` | `num_vertices + 1` | границы списков исходящих рёбер по вершинам |
| `csr_col_idx` | число рёбер | голова ребра (куда ведёт) |
| `edge_weight` | число рёбер | вес ребра (целое, ≥ 0) |

Вершины нумеруются `0 … num_vertices - 1`. Рёбра **ориентированные**: запись с индексом `e` — это ребро `u → v` с весом `w`, где `u` определяется по позиции `e` в CSR, `v = csr_col_idx[e]`, `w = edge_weight[e]`.

### Как читать исходящие рёбра вершины `u`

Для вершины `u` все её исходящие рёбра лежат подряд в `csr_col_idx` и `edge_weight` на индексах

```
e ∈ [csr_row_ptr[u], csr_row_ptr[u + 1])
```

Цикл по соседям:

```cpp
for (int e = csr_row_ptr[u]; e < csr_row_ptr[u + 1]; ++e) {
    int v = csr_col_idx[e];
    int w = edge_weight[e];
    // релаксация u → v с весом w
}
```

`csr_row_ptr` монотонно неубывает. В тестах **`csr_row_ptr[0] == 0`**, тогда число рёбер

```
num_edges = csr_row_ptr[num_vertices]
```

(иначе `num_edges = csr_row_ptr[num_vertices] - csr_row_ptr[0]`).

Порядок рёбер внутри одной вершины может быть любым; параллельные рёбра `u → v` с разными весами допустимы (хранятся отдельными записями).

### Пример

Граф из 4 вершин, рёбра: `0→1 (1)`, `0→2 (4)`, `1→2 (2)`, `1→3 (6)`, `2→3 (3)`:

```
csr_row_ptr = [0, 2, 4, 5, 5]
csr_col_idx = [1, 2, 2, 3, 3]
edge_weight = [1, 4, 2, 6, 3]
```

- у `0` два ребра: индексы `0,1` → `(1,1)` и `(2,4)`;
- у `1` два ребра: индексы `2,3` → `(2,2)` и `(3,6)`;
- у `2` одно ребро: индекс `4` → `(3,3)`;
- у `3` рёбер нет: `csr_row_ptr[3] == csr_row_ptr[4]`.
