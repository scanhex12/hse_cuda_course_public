# Streaming VAD

Задача: обработать длинную последовательность аудио-чанков на GPU, используя несколько CUDA streams, чтобы перекрывать передачи хост-устройство и вычисления.

## Амплитудный VAD

Для каждого чанка из `samples_per_chunk` сэмплов считаем `m = max_j |x_j|` и считаем чанк «речью», если `m >= threshold`, иначе «тишиной»:

- `host_vad[i] = 1` - речь;
- `host_vad[i] = 0` - тишина.

## Аргументы `run_streaming_vad`

Сигнатура объявлена в `streaming_vad.cuh`:

- `host_input` — указатель на сэмплы на хосте. Чанки лежат подряд: чанк с индексом `i` начинается по смещению `i * samples_per_chunk` (в элементах `float`). Длина массива в логике задачи равна `num_chunks * samples_per_chunk`.

- `host_vad` — буфер на хосте длины `num_chunks` байт (по одному `unsigned char` на чанк). После вызова в `host_vad[i]` записывается `0` или `1` по правилу выше. Память вызывающий код выделяет сам.

- `num_chunks` - сколько чанков обработать (`> 0`).

- `samples_per_chunk` - сколько `float` в одном чанке (`> 0`).

- `threshold` - порог амплитуды: если максимум модуля сэмплов в чанке не меньше этого значения, чанк помечается как речь.

- `num_streams` - сколько разных `cudaStream` использовать для перекрытия копий и ядер (`>= 1`). При `1` всё выполняется в одном потоке, перекрытия между чанками нет.

## Зачем streams

Один чанк: `H2D` -> `kernel` -> `D2H`. Пока на одном stream идёт, например, копирование следующего чанка, на другом может выполняться kernel по уже загруженным данным. В реальном пайплайне к микрофону данные тоже приходят чанками; здесь все чанки уже лежат в `host_input`, но порядок запусков должен быть как у стриминга: очередь из `num_streams` потоков, чанки распределяются по кругу `i % num_streams` (по сути round-robin-ом).

## Переиспользование буферов

Чанк с индексом `i` и чанк `i + num_streams` используют один и тот же индекс потока и тот же слот буфера на GPU, но на этом потоке они выполняются последовательно, поэтому данные не затираются преждевременно. Иначе говоря: держите по одному `d_chunk[s]` и одному флагу `d_flag[s]` на каждый `s` от `0` до `num_streams - 1`.
