# Triton Image — RGB → оттенки серого

## Задача

Дан цветной тензор изображения `img` формы **(H, W, 3)** . Нужно получить изображение того же размера, в котором каждый пиксель заменён на оттенок серого с той же яркостью по формуле люминанса:

\[
\text{gray} = 0{,}2 \cdot R + 0{,}5 \cdot G + 0{,}3 \cdot B
\]
